Draft Timeouts & Makeup Picks

No pick is ever lost. If a FantasyTeam's timer expires with no Administrator extension, that pick is skipped — not recorded — and queued as a makeup pick. Once the final regular round finishes, every queued team gets their turn, in the order they were skipped. If a makeup pick itself times out, it goes back to the end of the (now longer) queue and the same rule applies again (BR-282).

Why this matters

Without this rule, one missed connection could either freeze the entire draft or permanently cost a FantasyTeam a player. Skipping-and-requeuing keeps everyone else moving while guaranteeing every team still finishes with a full squad (BR-052/BR-060) — even a team that times out more than once.

This prediction is the last deterministic tie-break tier, used only if two FantasyTeams are still level after League Points, Fantasy Goal Difference, Fantasy Goals For, Head-to-Head Points, and Captain Points. The closest prediction to the actual season-end total wins; if two are equally close, the one at or below the actual total wins (BR-131–134).

CSRF Protection (BR-168)

Every state-changing request (draft picks, roster submissions, league messages, admin corrections) requires a bearer token in the Authorization header. Browsers never attach that header automatically on a cross-site request — the mechanism classic CSRF depends on — so the current API isn't exposed to it.

Current API · Not Exposed Cookie-Flow Middleware · Implemented, Standing By

If a cookie-based session flow is ever added (e.g., a future browser fallback), anti-CSRF tokens and SameSite cookie attributes activate automatically for that flow — not bolted on after the fact.
